# Personal creator hub

Read [hub operation](../../references/creator-hub.md). Use the owner-selected EmberBanter identity across the complete hub. Read [creative-suite contracts](../../references/creative-suite.md) for music, shell, automation and branding.

Discover actual tools and executing device before acting. Local stdio MCP runs on a suitable laptop host; account installation does not make it executable from ChatGPT mobile. Phone PWA access and ChatGPT tool access are separate connections.

Use studio_status and studio_library for actual state. Save a non-destructive session with studio_session_save. Use studio_project_save for projects, studio_import only with an actual owner-selected local file, and studio_document_read/write for versioned studio text. studio_shell executes the scoped command language; it cannot run OS commands. Use studio_workflows to discover actual recipes and studio_propose for an exact render, mix, music video, MIDI sketch, diagnostic check, named-app launch, bumper or allowed OBS action. Do not claim a proposal executed. Ask the owner to review the pending action in Connections in the hub; there is deliberately no agent approval tool. Existing explicit authorization still applies in scope, but never impersonate the owner through their browser session or use hidden API routes to approve.

Inspect source context and caption words/timing before setting review flags. Preserve unknowns; request the missing review if actual content cannot be inspected. Scene and mixer changes affect an already-live stream. Record only with the owner's instruction and participant consent. This hub does not start broadcasts or publish.

Read the actual job and receipt after execution. Full decode and checksum evidence do not prove editorial quality, rights clearance or hardware acceptance. Never invent progress, duration, audience figures or completed delivery. Correct failures before proposing a fresh action; ambiguous OBS responses must not retry automatically.

Keep the pairing key and OBS password out of chat, source and logs. Pair only owner devices over the configured private HTTPS origin. Never expose OBS ports or weaken authentication. Run the bundled hub only on the intended computer, with a separate private workspace outside Git.

For autonomous work, distinguish fixed local workflow execution from model-driven source engineering. Current planner/executor/verifier roles are deterministic code. Engineering checks rebuild a diagnostic report without changing source or calling model providers; read its passed field and failures. Do not claim a running agent swarm, native FLP editing, a full DAW or completed animation simply because an app is installed. A launch result only confirms the launch request.

Read [broadcast workflows](../../references/broadcast-workflows.md) for the capture inbox, packet-verified editing copies and multi-source episodes. Use studio_recordings only for the locally configured folder; prepare capture_import with a real stopped-recording/content review, never infer that age alone proves the capture finished. Episode captions use final arranged timestamps. Existing single-source Studio captions use source timestamps. Use discovered media IDs, explicit track/order/timing and reviewed permissions; inspect actual imports, chapter metadata and delivery receipts after execution. The brand kit presents Gaming, Streaming and Podcasts; preserve Music. Games. Stories.

Current creator control: read [creative control contracts](../../references/creative-control.md) for actual local narration, versioned storyboards, platform draft handoffs, encoder evidence and reviewed history replay. Editing remains an app function; remove editing and music-production/video category labels from the brand kit. Preserve the selected badge, palette and Music. Games. Stories.
