# Personal creator hub

Read [hub operation](../../references/creator-hub.md). Keep EmberBanter as the current identity until the owner chooses a replacement.

Discover actual tools and executing device before acting. Local stdio MCP runs on a suitable laptop host; account installation does not make it executable from ChatGPT mobile. Phone PWA access and ChatGPT tool access are separate connections.

Use studio_status and studio_library for actual state. Save a non-destructive session with studio_session_save. Use studio_propose for an exact render, bumper or allowed OBS action. Do not claim a proposal executed. Ask the owner to review the pending action in Connections in the hub; there is deliberately no agent approval tool. Existing explicit authorization still applies in scope, but never impersonate the owner through their browser session or use hidden API routes to approve.

Inspect source context and caption words/timing before setting review flags. Preserve unknowns; request the missing review if actual content cannot be inspected. Scene and mixer changes affect an already-live stream. Record only with the owner's instruction and participant consent. This hub does not start broadcasts or publish.

Read the actual job and receipt after execution. Full decode and checksum evidence do not prove editorial quality, rights clearance or hardware acceptance. Never invent progress, duration, audience figures or completed delivery. Correct failures before proposing a fresh action; ambiguous OBS responses must not retry automatically.

Keep the pairing key and OBS password out of chat, source and logs. Pair only owner devices over the configured private HTTPS origin. Never expose OBS ports or weaken authentication. Run the bundled hub only on the intended computer, with a separate private workspace outside Git.
