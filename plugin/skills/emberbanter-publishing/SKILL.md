# Publishing preflight

Read [podcast/publishing guide](../../references/podcast-and-publishing.md), [local commands](../../references/local-commands.md) and [primary sources](../../references/research-sources.md). Confirm the real destination, channel ownership and media. Drafting is not publishing; carry out publication only when requested and supported by an actual connected tool.

Review the final audio/video, title, description, accurate explicit flag, guest permission and music/game rights. Generate chapters and quotations only from real media/transcripts. Keep unsupported audience promises and invented sponsor rates out of release copy.

For RSS, use the bundled builder with the included [show example](../../assets/examples/show.example.json) and [episode example](../../assets/examples/episodes.example.json) as shape references. Replace example URLs, byte counts, durations and GUIDs with actual production values. Preserve GUIDs after publication. --draft permits example domains and produces only a demonstration. Without --draft, local validation still cannot prove external availability.

The builder supports Leisure / Video Games and stable HTTPS enclosure URLs without expiring query tokens. Verify the host's public feed, artwork, media MIME/length, HEAD and byte-range support, and current destination validation. The plugin logo is not automatically valid podcast cover art. A private repository is not an RSS media host.

Deliver final reviewable metadata/XML and a short, evidence-based remaining-check list. Report actual submission/dashboard results separately if publication is authorized and completed. Never claim Apple/Spotify distribution or Twitch/YouTube publishing from a local file alone.
