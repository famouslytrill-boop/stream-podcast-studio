# Stream setup

Read [technical playbook](../../references/technical-playbook.md) and [known gear/state](../../references/brand-and-state.md). Inventory the actual selected device with available device tools; a cloud executor is a separate machine. Check device availability before claiming installation.

Use official vendor installers or verified registry package IDs. The source repository has a Windows installer with a plan mode. Run only the authorized installs, retain results and verify the actual installed versions. Do not disable OS security, firewall rules or authentication to make an install work.

Test existing Remote Play/capture options before proposing a purchase. Follow the playbook's single-capture mic/game routing and party-chat distinctions. Add the [existing HTML scenes](../../assets/brand/START_HERE.txt) as browser sources; keep the assets folder together. A scene HTML file is not an imported OBS scene collection.

Run the five-minute saved-recording acceptance checks, BRB silence and OBS Stats under load. Use the engineering skill's preflight tool only with actual measurements/operator confirmations. Unchecked is unverified, never pass. For device work blocked by an offline PC, complete independent instructions/assets and identify exactly what remains.

Return the observed route, saved-recording result, specific failure/fix and next device test. A local or unlisted test is not assumed on Twitch; obtain the owner's go-live intent when needed.
