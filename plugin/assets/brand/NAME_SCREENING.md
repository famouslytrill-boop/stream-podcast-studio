## Finish the name check

1. Try `emberbanter` in the signed-in Twitch and YouTube handle fields.
   A search result, empty profile page or display name is not a reservation.
2. Check matching TikTok and Instagram usernames if you intend to use them.
3. Save a confirmed handle in each platform and record the real channel URLs.
4. If a similar active gaming/entertainment brand appears, reassess the name
   rather than automatically adding numbers. Do not copy another channel's look.
5. Before paid merchandise, registration or a major brand spend, complete
   an exact and similar-name trademark search using the official USPTO system.
   No legal clearance or worldwide exclusivity is claimed here.
